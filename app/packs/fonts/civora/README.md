# Civora fonts

Self-hosted woff2 files, byte-identical to `fonts/` in `civora-org/civora-site` (civora.sk), so the platform and the site set their type from the same files.

| Family | Weights | Subsets | Licence |
| --- | --- | --- | --- |
| Alegreya Sans | 700 | latin, latin-ext | SIL Open Font License 1.1 |
| Source Sans 3 | 400, 600, 700 | latin, sk-ext | SIL Open Font License 1.1 |

The licence text and copyright lines are in [`OFL.txt`](OFL.txt). The `@font-face` rules are in `app/packs/stylesheets/decidim/civora/_fonts.scss`. No font is loaded from a third-party host.
